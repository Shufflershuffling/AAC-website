AAC website deployment

Upload ALL files in this folder to the public website root for https://www.ausasiaconnect.com/
Keep index.html, favicon.png, favicon-48.png, apple-touch-icon.png, social-preview.jpg, robots.txt and sitemap.xml together.

Before launch: verify canonical domain and redirect alternate hostnames to it; ensure HTTPS; test responsive layouts, all links, accessible alt text, and page loading; verify logo usage and quotes.
After launch: submit sitemap.xml in Google Search Console and Bing Webmaster Tools; request indexing; verify robots.txt and social image URLs return HTTP 200; validate structured data.

Search appearance is not guaranteed and indexing can take time.
